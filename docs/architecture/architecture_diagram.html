Dynamic Tiered KV Caching with Priority Scoring, Selective Quantization, and CPU Compute Delegation

HOST SYSTEM LAYER (Host CPU & System Memory)
System RAM (16–32 GB)
📦 Host DRAM Cache Pool
  • Compressed Low-Priority KV Tier: Quantized 4-bit tensors offloaded from VRAM.
  • Inactive Multi-User Sessions: Dormant SME conversations paged out to save active memory.
  • Page-Aligned Buffer Layout: Zero-copy pinning for asynchronous DMA over PCIe.
⚙️ CPU Compute Delegation Workers
  • Idle Thread Harvest: Utilizes spare multi-core CPU cycles during GPU decode loops.
  • Vectorized Dequantization: SIMD / AVX-512 kernels decompressing INT4 → FP16.
  • Zero GPU Overhead: Fully relieves GPU Tensor Cores from decompression computation.
PCIe Gen3 / Gen4 Motherboard Interconnect
Bidirectional Asynchronous Pipelined Transfer Channel (16–32 GB/s)
⚡ 75% Bus Traffic Reduction (via 4-bit transfers)
🔄 Overlapped Transfer & GPU Kernel Execution
TARGET ACCELERATOR LAYER (Consumer GPU VRAM 8–16 GB)
GDDR6 VRAM (~272 GB/s)
🧠 Priority Engine & Cache Routing Core
  • Dynamic Priority Scorer: Score = Weight × Recency evaluated during decoding.
  • PagedBlock Allocator: Non-contiguous physical chunk management (PagedAttention).
  • Selective Tiering Dispatcher: Keeps top tokens in VRAM; streams lower tier to CPU.
🔥 Active VRAM & Execution Core
  • High-Priority Cache (16-bit): Attention Sinks (1–4) + Heavy Hitters ($H_2$).
  • Full Reasoning Fidelity: Critical context never quantized or dropped.
  • Execution Engine: FlashAttention fused decoding & next-token generation.
Architecture Workflow: Initial tokens are pinned $\to$ Attention priority dynamically ranks context $\to$ Low-priority tokens offload as 4-bit to Host RAM $\to$ CPU dequantizes recalled tokens before streaming back across PCIe without GPU stall.
